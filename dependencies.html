Dependencies

What #Hex Next needs on your phone, and what each part lets it theme. When the app says Dependency missing, the part it is waiting for is on this page.

For theming: root or Shizuku

  • Root with any root manager, such as KernelSU, Magisk or APatch, or Shizuku running as root: every part of a theme, from colours to icons, fonts, pictures and pack art.
  • Shizuku over wireless debugging, without root: the accent colour only.

#Hex Next asks for root or Shizuku itself the first time it needs it. It never roots a phone.

For the System UI features: the System UI module

System UI draws some of its parts in code, so a theme's overlays cannot reach them on their own. The free HexNext-QS-Notifications-Module is an LSPosed module that lets #Hex Next theme those parts too:

  • Quick panel tiles in full colour, with the theme's art inside each tile icon
  • the circles of the tiles that are on, in up to three colours
  • the volume popup and the Quick panel's volume and brightness bars, in up to three colours
  • the status bar icon colours on the lock screen and the closed status bar
  • notification card art and the Quick panel music player icons

The multi-colour tile circles, the Quick panel's bars and the lock screen's status bar colours need One UI 9. Without the module, #Hex Next still themes everything else, and these parts keep One UI's own look or a single colour.

What the module needs

  1. A rooted phone with Zygisk, for example Zygisk Next with KernelSU, or Magisk's own Zygisk.
  2. Vector or LSPosed, the framework that runs the module inside System UI.
  3. The module itself, with System UI ticked in its scope.

Get the module and its steps

Once the module runs, the System UI card in #Hex Next (Theme Packs) says it is active, and its switches turn each part on or off. After installing or updating the module, restart System UI with a soft reboot before you apply a theme again.

Before you install anything

Root managers, Zygisk and module frameworks are made by independent developers, not by #Hex Next. Rooting can void your warranty or trip Samsung Knox. Follow each project's own instructions. The module only changes how System UI draws the parts listed above, only for themes from #Hex Next, reads nothing else and sends nothing anywhere.
