Setup guide

Temporary root on a Samsung Galaxy phone, then Zygisk, Vector (LSPosed) and the HexNext-QS-Notifications-Module, so #Hex Next can theme everything, including full-colour Quick panel tiles and notification card art.

Rooting can void your warranty, trip Samsung Knox and, in rare cases, stop a phone from starting normally. These tools are made by independent developers, not by #Hex Next. Follow each project's own instructions, keep a backup, and only use them on a phone you own.

Before you start: locked bootloaders

  1. Stay off new security updates. Temporary root on a locked bootloader is confirmed to work up to the October 2026 security update so far, but Samsung will patch the exploit soon. Avoid installing security updates, and turn off Auto update system in Developer options.
  2. Never change anything that runs while the phone is starting. With a locked bootloader, any setting that modifies the phone during boot will almost certainly brick it or leave it in a boot loop. Only changes made after the phone has finished starting are safe, such as getting root again automatically once it has booted.
  3. Don't touch settings you don't understand. In Root My Galaxy and KernelSU, never apply a setting before you know exactly what it does.
  4. Keep modules to a minimum. Only install KernelSU modules you absolutely need, such as Zygisk (required for any module to work) and Vector (LSPosed).

1. Get root

Pick the method that matches your phone and its security update (Settings › About phone › Software information).

Check the community guide first: Awesome Temporary Root. Which method works depends on your exact model, firmware build and kernel, and it changes with every security update. That guide keeps the current list, so #Hex Next links to it in the app as well: on the welcome screens, in the in-app guide and under Settings › Root help.

In the guide: Samsung Galaxy phones · Quick start · Modules · Troubleshooting

The methods below are the ones #Hex Next users have confirmed on Galaxy phones. If the community guide lists something newer for your phone, follow the guide.

Root My Galaxy

Works for older devices on older security updates.

Root My Galaxy Next

The continuation of Root My Galaxy, for newer models and security updates.

DirtyFrag + Diabl0w's KernelSU

These two go hand in hand. Together they work on almost every Samsung device up to about the June or July 2026 security update.

Root My Galaxy Ultra

Works on the September and October 2026 security updates.

KernelSU-Next

The best root manager to use with any Root My Galaxy method.

KernelSU asks you to upgrade after Root My Galaxy?

  1. Open KernelSU-Next › Actions › Build Manager CI.
  2. Open the latest workflow run that passed and download its manager file.
  3. Use it to update your KernelSU-Next manager. This usually fixes it without rooting again.
  4. If it doesn't, try the next older passed run, and keep going down the list until you find the version that matches your phone. Be patient: one of them will work.

2. Install Zygisk and Vector

  1. Download any one Zygisk variant: Zygisk Next, NeoZygisk or ReZygisk. Whichever you like. Install it in KernelSU › Modules, then reboot.
  2. Download Vector (the current LSPosed), install it in KernelSU › Modules, then reboot again.

Soft reboot every time you grant root. With temporary root, root comes back only after you run your root method again following a restart. Each time you do, perform a soft reboot so Zygisk loads. Every other module, Vector included, depends on it.

3. Install the HexNext-QS-Notifications-Module

Download HexNext-QS-Notifications-Module.apk

Owner and beta builds of #Hex Next can also install it for you: Theme Packs › System UI hook › Install module.

  1. Install the APK.
  2. Open Vector from its notification, or from KernelSU › Modules › Vector.
  3. With Vector open, go to the Modules tab and tap HexNext-QS-Notifications-Module. Don't enable it yet.
  4. Tick System UI in its scope first. You may need to use the filter to show system apps.
  5. Once System UI is ticked, switch the module on with the toggle in the top right corner, then reboot.

You're set

#Hex Next can now theme your phone to its fullest, with no further setup. The hook loads by itself every time you grant root after a restart. Just don't forget the soft reboot each time, or Zygisk won't load and the modules that depend on it won't run.

In #Hex Next, Theme Packs › System UI hook shows Hook active once it is running. Turn on Quick panel tiles in full colour and Notification card art there.
