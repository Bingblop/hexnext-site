    How to set it up

    You need root with Zygisk (Zygisk Next or ReZygisk on KernelSU, or Magisk's Zygisk) and Vector, the current LSPosed.

    1. Install the APK. Owner and beta builds of #Hex Next can install it for you from the System UI hook card.
    2. Open Vector › Modules and tap HexNext-QS-Notifications-Module.
    3. Tick System UI in its scope first, then switch the module on.
    4. Restart the phone. The System UI hook card in #Hex Next then says Hook active.

    Is it safe?

    The module only changes how System UI draws tile icons, the status bar icons and notification card backgrounds, and only for themes from #Hex Next. It reads nothing else and sends nothing anywhere. To stop it, switch it off in Vector and restart.

    FAQ

    Questions

    Which phones work?

    Samsung Galaxy phones on One UI 7, 8 and 9 (Android 15 to 17). #Hex Next themes Samsung's own system apps.

    Do I need root?

    Full theming needs root (any root manager, such as KernelSU or Magisk) or system access through Shizuku running as root. Without root, Shizuku over wireless debugging can still apply the accent colour. The setup guide lists the root methods for each security update, and the community's Awesome Temporary Root guide keeps the current method for every model.

    Is it safe? Can I undo it?

    Yes. Test Mode tries a theme only until the next restart, Remove takes every overlay off in one tap, and a recovery watchdog turns the theme off if System UI keeps crashing after a restart. #Hex Next never touches your files.

    Do I need my own AI key?

    No. Two free, experimental agents work out of the box, though their themes may be lower quality. For the best results add a key for any supported service. A Google Gemini key is free and needs no card: get one at aistudio.google.com.

    How many theme packs are there?

    More than 50, from minimal to wild, with new packs added regularly. Any theme you build can also be saved as your own pack.

    What happens to my data?

    Your themes, images and fonts stay on your phone. Read the privacy policy for the details.
